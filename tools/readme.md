# roLabelImg 用户指南

`roLabelImg` 是一款图形化图像标注工具，专为高效标注图像中的物体而设计，尤其侧重于比较不同时间周期的图像（例如 2010、2015 和 2020 年）。它允许您绘制标准的矩形边界框和旋转的边界框，适用于广泛的目标检测任务。

该界面并排显示三张图像，便于在不同年份之间进行轻松比较和一致性标注。为了使标注过程尽可能快，该工具针对键盘操作进行了大量优化。

##核心功能

* **三面板视图**：同时查看和标注来自三个不同年份的图像。
* **旋转边界框**：除了标准的矩形框（`B` 键），还可以使用 `E` 键为非轴对齐的物体创建旋转边界框。
* **高效的键盘快捷键**：提供一套全面的快捷键，用于导航、标注和添加标签。
* **专业化标签**：用于快速分类不同类型大坝的快捷键。
* **智能导航**：直接跳转到未标注、有特定标签或包含极小标注的图像组。
* **进度跟踪**：通过激励性的进度条来跟踪您的标注进度。
* **坐标显示**：查看并复制主图像左上角的地理坐标。

## 快捷键

与 `roLabelImg` 交互的主要方式是通过其键盘快捷键。

---

### **导航**

这些快捷键可以帮助您在图像之间快速移动。

| 快捷键 | 功能 | 描述 |
| :--- | :--- | :--- |
| `A` | **上一图像组** | 加载前一组三张图片。 |
| `D` | **下一图像组** | 加载后一组三张图片。 |
| `Shift`+`A` | **上一个已标注组** | 跳转到上一个至少有一个标签的图像组。 |
| `Shift`+`D` | **下一个已标注组** | 跳转到下一个至少有一个标签的图像组。 |
| `Ctrl`+`A` | **上一个有变化的组**| 跳转到上一个在不同年份间标签有变化的图像组。 |
| `Ctrl`+`D` | **下一个有变化的组** | 跳转到下一个在不同年份间标签有变化的图像组。 |
| `Shift`+`Z` | **上一个未标注组**| 跳转到上一个在所有年份都没有标签的图像组。 |
| `Shift`+`C` | **下一个未标注组** | 跳转到下一个在所有年份都没有标签的图像组。 |
| `Shift`+`Q` | **上一个大坝标签** | 跳转到上一个包含“大坝”标签的图像组。 |
| `Shift`+`E` | **下一个大坝标签** | 跳转到下一个包含“大坝”标签的图像组。 |
| `Ctrl`+`V` | **下一个小标注** | 跳转到下一个包含小于设定阈值的标注的图像组。 |
| `Ctrl`+`Shift`+`V` | **上一个-小标注**| 跳转到上一个包含小于设定阈值的标注的图像组。 |

### **标注与标签**

这些快捷键用于创建、修改和删除标签及边界框。

| 快捷键 | 功能 | 描述 |
| :--- | :--- | :--- |
| `B` | **创建矩形框** | 进入绘制标准矩形框的模式。 |
| `E` | **创建旋转框** | 进入绘制旋转矩形框的模式。 |
| `Delete`| **删除选中框** | 删除当前选中的标注框。 |
| `Alt`+`D` | **复制选中框** | 创建一个选中标注框的副本。 |
| `0` | **编辑标签** | 打开一个对话框来修改所选标签的文本。 |
| `Space` | **验证并下一张** | 将当前图像标记为已验证，保存，并移动到下一组。 |

---

### **跨年份标注**

使用这些按键来管理三个图像面板（2010, 2015, 2020）中的标签。

| 快捷键 | 功能 | 描述 |
| :--- | :--- | :--- |
| `1` | **添加到 2010** | 将选中的标注复制到 2010 面板（左侧）。 |
| `2` | **添加到 2015** | 将选中的标注复制到 2015 面板（中间）。 |
| `3` | **添加到 2020** | 将选中的标注复制到 2020 面板（右侧）。 |
| `4` | **从 2010 删除** | 删除 2010 面板中与选中框重叠的任何框。 |
| `5` | **从 2015 删除** | 删除 2015 面板中与选中框重叠的任何框。 |
| `6` | **从 2020 删除** | 删除 2020 面板中与选中框重叠的任何框。 |
| `7` | **删除所有重叠项** | 删除选中的框以及在所有三个面板中与之重叠的任何框。 |
| `8` | **删除并下一组** | 删除选中的框及其所有重叠项，保存，并移动到下一图像组。 |

### **快速标签（用于大坝）**

选中一个框后，使用这些键可以快速将其分类为一种大坝类型。这将更改选中框以及其他年份中所有重叠框的标签。

| 快捷键 | 功能 |
| :--- | :--- |
| `/` | **土石坝 (Embankment Dam)** |
| `*` | **拦河坝 (Barrage Dam)** |
| `-` | **重力坝 (Gravity Dam)** |
| `+` | **拱坝 (Arch Dam)** |

### **文件操作**

| 快捷键 | 功能 | 描述 |
| :--- | :--- | :--- |
| `Ctrl`+`U` | **打开目录** | 打开包含图像组的目录。工具将按前缀自动分组图像（例如 `image_2010.jpg`, `image_2015.jpg`）。 |
| `Ctrl`+`S` | **保存** | 保存当前图像组的标注。标注将作为 `.txt` 文件保存在指定的输出目录中。 |
| `Ctrl`+`R` | **更改保存目录**| 设置将要保存标注文件的默认目录。 |
| `Ctrl`+`Shift`+`O`| **设置输出目录** | 为最终图像和标签文件设置单独的输出目录。 |
| `P` | **复制到输出** | 将当前图像组及其标签复制到指定的输出目录。 |
| `Ctrl`+`Q` | **退出** | 关闭应用程序。 |
